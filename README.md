# Rubi Airline CRM

Rubi یک CRM ماژولار برای شرکت خدمات مسافرتی و هواپیمایی است. محصول به‌صورت
تدریجی در قالب Modular Monolith و Monorepo توسعه داده می‌شود. رابط کاربری فارسی
و RTL است و نام‌گذاری کد، API و دیتابیس به انگلیسی انجام می‌شود.

این Repository فعلاً در مرحله Bootstrap مستندات است و هنوز کد اجرایی یا Migration
ندارد.
