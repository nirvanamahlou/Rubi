# راهنماهای نورا

سندهای این پوشه مرجع متن نمایش‌داده‌شده در نورا و صفحهٔ راهنمای روبی هستند.

- شناسهٔ هر بخش را در anchor و فراداده حفظ کنید.
- مراحل را زیر عنوان «مراحل» با فهرست شماره‌دار، هر مرحله در یک خط، بنویسید.
- ارجاع‌های `related` از شناسهٔ سند و بخش ساخته می‌شوند. پیوند Markdown همان مقصد را برای خواننده نشان می‌دهد.
- پس از ویرایش، از ریشهٔ مخزن `node scripts/build-assistant-guides.mjs` را اجرا و خروجی‌های JSON را همراه سند ثبت کنید.
- فرمان `node scripts/build-assistant-guides.mjs --check` تطابق خروجی‌ها را بررسی می‌کند.

سندهای پنل دارای بلوک فرادادهٔ `nora-catalogue` برای پیام‌های کمکی مشترک هستند. خروجی‌های اختصاصیِ کاتالوگ و نمایهٔ صفحهٔ راهنما هر دو از همین سندها تولید می‌شوند. متن مراحل را فقط در بخش «مراحل» سند تغییر دهید. هر ارجاع داخل سند باید هم در `related` و هم به‌صورت لینک Markdown ثبت شود. پس از ساخت، خروجی‌های تغییریافته را با Prettier قالب‌بندی کنید.
