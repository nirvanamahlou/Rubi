# APP-SHELL-HEADER-UTILITY-LEFT-001

## هدف

گروه تاریخ و کنترل‌های کاربر در نمایش دسکتاپ باید به‌صورت یک بلوک منسجم در لبه چپ نوار بالا قرار گیرد و فضای خالی سمت چپ باقی نماند.

## محدوده

- چیدمان `AppShell` و تست متمرکز هدر.
- حفظ ترتیب و رفتار تاریخ، زبان، پوسته، اعلان و منوی کاربر.
- بدون تغییر API، داده، IAM، Schema/Migration یا وابستگی.

## وضعیت

پیاده‌سازی روی `codex/pc-a-header-utility-left` از `origin/develop@dd177cfd` کامل شد. تاریخ و HeaderActions در یک بلوک واحد با `ms-auto` قرار گرفتند؛ ۴ تست متمرکز، lint، Web typecheck و build تولیدی ۴۶ مسیر موفق بود.
