# CUSTOMER-AFFAIRS-QA-FIXES-0923

## نتیجه

ایرادهای قطعی گزارش QA امور مشتریان و پشتیبانی بدون Migration یا تغییر وابستگی
رفع شدند:

- داشبورد برای هر کاربر احراز‌شده، قابلیت‌های مجاز همان نقش را برمی‌گرداند و
  فقط شمارنده‌های دامنه‌های مجاز را query می‌کند؛ نقش دارای مجوز جزئی دیگر در
  نمای پیش‌فرض با 403 متوقف نمی‌شود.
- گزارش روی صفحه به مجوزهای خواندن درخواست و تیکت وابسته است؛ مجوز export برای
  عملیات خروجی فایل باقی می‌ماند.
- Web تب‌ها، شمارنده‌ها، فهرست‌ها و دکمه‌های ایجاد را بر اساس قابلیت سرور نمایش
  می‌دهد. پاسخ 401 با پیام انقضای نشست و مسیر ورود مجدد از 403 تفکیک شده است.
- تمام FormFieldهای عملیاتی ماژول که شناسه صریح نداشتند، شناسه پایدار رندر،
  `htmlFor`، `aria-describedby` و `aria-invalid` دریافت می‌کنند. پس از ثبت موفق
  نیز شماره پیگیری در پیام موفقیت نمایش داده می‌شود.
- سربرگ تکراری گزارش حذف شد و زمان تازگی گزارش حفظ شد. اعتبارسنجی بازه تاریخ به
  تابع خالص منتقل شد تا تست مرزی بدون timeout تقویم اجرا شود.
- fixture محلی از DATABASE_URL ورودی استفاده می‌کند و دیگر نام دیتابیس مخفی را
  جایگزین نمی‌کند. ۱۲ تیکت synthetic با کانال Website به‌صورت مساوی و تکرارپذیر
  به `jahanbastan` و `nystkt` متصل شدند.
