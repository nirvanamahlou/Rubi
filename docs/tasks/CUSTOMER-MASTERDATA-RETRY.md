# CUSTOMER-MASTERDATA-RETRY

## مسئله

Customers چهار فهرست Organization، نحوه آشنایی، کشور و شهر را فقط از Public Master
Data API می‌خواند. اگر Access Session منقضی می‌شد، درخواست Customers نشست را تمدید
می‌کرد اما درخواست‌های هم‌زمان اطلاعات پایه با پاسخ 401 خاتمه می‌یافتند و UI پیام
«اطلاعات پایه در دسترس نیست» را تا بارگذاری مجدد صفحه نشان می‌داد.

## اصلاح

- فقط پاسخ 401 اطلاعات پایه باعث یک بار تمدید نشست و تکرار همان درخواست می‌شود.
- پاسخ 403، خطای شبکه و خطای سرور بدون تکرار پنهان باقی نمی‌مانند و رفتار خطای موجود
  را حفظ می‌کنند.
- از همان Public Master Data API استفاده می‌شود؛ دسترسی مستقیم به Repository یا جدول
  Master Data اضافه نشده است.
- تمام قابلیت‌های قبلی Customers در همین مبنا موجودند. پاسپورت و ویزای ساختاری همچنان
  به‌دلیل بازبودن `DEC-OPEN-006` فعال نشده‌اند و هیچ داده ساختگی نمایش داده نمی‌شود.

## اثبات مبنا

Commitهای `f8ec2f8`، `c09183f`، `ff55b68`، `b34a376`، `e8cd4bc` و `3bdd8de`
همگی ancestor نسخه فعال‌اند؛ بنابراین Persistence کد ملی، کد ملی مستقل مسافر، Reveal،
اطلاعات تکمیلی مسافر و اتصال Documents از نسخه حذف نشده‌اند.
