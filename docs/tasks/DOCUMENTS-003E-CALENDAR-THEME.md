# DOCUMENTS-003E — تم تقویم‌های بخش اسناد

وضعیت: آماده بررسی روی Branch مستقل `codex/pc-b-documents-calendar-theme`؛ مبنا
`origin/develop@45b6b11` است و `develop` یا `main` مستقیم تغییر نکرده‌اند.

## نتیجه

سه تقویم بخش اسناد با ظاهر Rubi یکدست شدند:

1. «ثبت از تاریخ» در فیلتر همه اسناد.
2. «ثبت تا تاریخ» در فیلتر همه اسناد.
3. «تاریخ اعتبار» در فرم بارگذاری فایل.

DatePicker مشترک یک Variant صریح `rubi` دارد. این Variant از Accent آبی–فیروزه‌ای،
Header گرادیانی، آیکن رنگی، Popover دارای عمق و وضعیت‌های واضح Hover، امروز و انتخاب
استفاده می‌کند. رنگ‌های اصلی زمینه، Border و متن از Theme Tokenهای Rubi می‌آیند تا ظاهر
در تم روشن و تیره خوانا و هماهنگ بماند.

Variant پیش‌فرض بدون تغییر باقی مانده است؛ بنابراین ماژول‌های دیگر فقط در صورت انتخاب
صریح `variant="rubi"` ظاهر جدید را دریافت می‌کنند.

## رفتار و دسترس‌پذیری

- انتخاب و مقدار ISO قبلی بدون تغییر است.
- تقویم شمسی و میلادی و جابه‌جایی ماه حفظ شده‌اند.
- نقش Dialog، نام دکمه‌ها، وضعیت Pressed و کنترل صفحه‌کلید حفظ شده است.
- تعویض شمسی به میلادی، انتخاب روز و بستن با کلید `Escape` در مرورگر محلی بررسی شد.

## مرز تغییر

هیچ Backend، Database، Schema/Migration/Seed، قرارداد عمومی، Permission، Dependency،
Lockfile، داده کاربردی یا Secret تغییر نکرد. این کار فقط UI مشترک به‌صورت افزایشی، مصرف
آن در Documents، تست و اسناد وضعیت همین Task را پوشش می‌دهد.
