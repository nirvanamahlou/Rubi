## هدف

ساخت یک منوی داخلی جمع‌شونده در صفحه `/finance` برای تفکیک حوزه‌های حسابداری، بدون
پیاده‌سازی فرم، جدول، محاسبه، API یا داده عملیاتی پیش از دریافت جزئیات مالک محصول.

## ساختار تاییدشده

- دفتر کل: اطلاعات پایه، حساب‌ها، اسناد، عملیات پایان سال، گزارش‌ها
- دریافت و پرداخت: گزارش پرداخت و دریافت
- ارتباط با سامانه مودیان مالیاتی: فعلاً بدون زیرگروه
- حسابداری مالیاتی: فعلاً بدون زیرگروه

هر مقصد فقط یک پوسته خالی با عنوان و پیام «در انتظار تعریف جزئیات» خواهد بود. این Task
هیچ قابلیت حسابداری یا اتصال مالیاتی را فعال‌شده معرفی نمی‌کند.

## نتیجه پیاده‌سازی

- صفحه `/finance` به پوستهٔ جدید حسابداری با منوی داخلی مستقل و جمع‌شونده متصل شد.
- برای هر ورودی مسیر پایدار زیر `/finance/accounting/**` ساخته شد و وضعیت انتخاب‌شده
  در منو و breadcrumb مشخص می‌شود.
- در نمایش عریض، منوی داخلی کنار سایدبار اصلی قرار می‌گیرد و در نمایش کوچک به چیدمان
  عمودی تبدیل می‌شود.
- محتوای تمام مقصدها عمداً به Empty State محدود است؛ هیچ فرم، جدول، داده نمونه، API،
  Permission، Schema یا Migration اضافه نشده است.
