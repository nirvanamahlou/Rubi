# HR-008 — Connected forms and selected-record exports

PC-B / `codex/pc-b-hr-connected-forms`, based on HR-007 `54c5ed7`.

The owner requested simpler HR forms that use previously entered records, remove duplicate employee/company inputs and export explicitly selected rows. This delivery retains the current Rubi theme and HR sections.

## Result

- Branch effective date, unit manager, interview job title and equipment serial number are omitted from forms, lists and exports. Their existing stored column positions remain unchanged, so old records/imports do not shift or lose values. The unit hierarchy uses a clearly named parent-unit selector instead of the generic related-case field.
- Company, employee, unit, position, grade, reviewer, job opening and other catalog references use permitted stored HR data. Inactive/deleted catalog entries and other company scopes are excluded. Text fields used to create catalog names remain editable; identifiers remain automatic. Duplicate employee/company and related-record inputs are represented once.
- Org-chart node placement selects an existing unit, with selectable company, level and parent; editing updates that unit instead of creating a duplicate. New units can still be created in the units list and appear in the chart. Existing server checks prevent cycles and invalid branch relations.
- Applicant creation requires choosing a recorded job opening. HR API stores the opening's actual title and parent FK, validates the resource and company scope, and supports changing the link with optimistic version checks. Legacy unlinked records/imports remain compatible.
- Promotion forms select current/new positions from the positions catalog. Current position defaults from the employee and must match the employee's record before submission; existing approval logic remains authoritative for applying the new assignment.
- All HR tables provide row/page checkboxes. XLSX/PDF actions export selected authorized rows; changing filters clears the effective selection. Generic server-paged lists preserve selection across pages and re-fetch permitted records before exporting. The duplicate statistics/export panel below operational lists is removed.
- Simple populated tables no longer show redundant View buttons. Employee names still open dossiers; applicant attachments, training details and approval workflows remain accessible through their record names. Contract detail headers show status and PDF without the version/employee shortcut.
- Expense receipts accept a real file upload and use the existing public Documents API. The persisted HR record contains the archive document reference. Document permissions, retention, antivirus and sensitive-file access controls are unchanged.
- Removed the visible current-section caption. New-employee required branch/unit validation now also handles empty catalog selections.
