## هدف و محدوده

نسخه دوم قرارداد عمومی IAM، Permission Codeهای لازم برای `MASTER-002` و
`CUSTOMER-001` را منتشر می‌کند. Seed موجود همین Permissionها را به‌شکل تکرارپذیر
می‌سازد و به نقش سیستمی `administrator` متصل می‌کند. مدل، Migration و Repository داخلی
IAM تغییری نمی‌کنند.
