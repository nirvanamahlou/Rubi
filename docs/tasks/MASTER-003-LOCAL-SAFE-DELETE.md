# حذف امن اطلاعات پایه — PC-B

وضعیت: آماده Review؛ انتشار با تأیید کاربر در 2026-08-31 روی `codex/pc-b-master-data-safe-delete`، Stacked روی شاخه وضعیت همکاری. والدها تغییر نمی‌کنند.

## محدوده و هماهنگی

- مجوز کار: تأیید کاربر برای حذف دائمی فقط رکوردهای بدون وابستگی، با تأیید UI،
  کنترل مجوز و حفظ Audit. مالک ماژول `PC-B/MASTER-003` است.
- Producer: Master Data API؛ Consumer: Master Data Web، هر دو PC-B.
- قرارداد افزایشی سازگار با v12: `DELETE /api/v1/master-data/:resource/:id` با
  `{ version: number }` و پاسخ `200 { data: { id, resource, deleted: true } }`.
- مجوز موجود `master_data.delete` الزامی است. Actor و شعبه مجاز Audit از Session
  می‌آیند؛ Legal Entity یا Branch مالک داده‌های مشترک نمی‌شود.
- فایل‌های تغییرکرده چت اصلی، WORK_ASSIGNMENTS، اسناد وضعیت مرکزی، IAM، Customers،
  Schema/Migration/Seed، Dependency/Lockfile و تنظیمات سرورها خارج از این اصلاح‌اند.
  این سند ثبت محلی محدوده است؛ قفل جدید یا تغییر شاخه مشترک انجام نمی‌شود.

## ایمنی

- FKهای موجود `ON DELETE RESTRICT` مرجع نهایی تشخیص مصرف رکورد هستند؛ Query مستقیم
  به ماژول دیگر یا Cascade حذف رکوردهای وابسته مجاز نیست.
- فقط اتصال‌های داخلی متعلق به خود Aggregate (Role سازمان، خدمات تأمین‌کننده/کارگزار،
  امکانات/اتاق/Meal هتل، اعضای هتل ترکیبی، پوشش‌های طرح و امکانات نوع اتوبوس) همراه
  مالک آزاد حذف می‌شوند. خودِ رکوردهای مقصد دست‌نخورده می‌مانند.
- Claim نسخه، پاک‌سازی اتصال‌های داخلی، حذف و Audit در یک Transaction هستند؛ خطای
  FK، رقابت هم‌زمان یا خطای Audit کل عملیات را Rollback می‌کند.
- نرخ غیر-Draft تاریخچه محسوب می‌شود و حذف نمی‌شود. Audit حذف فقط شناسه و نسخه
  قبلی را نگه می‌دارد؛ کپی جدید PII، مقدار رمز‌شده یا مشخصات تماس ثبت نمی‌کند.
- قراردادهای مصرف آینده باید FK Restrict یا قرارداد عمومی محافظت از مصرف داشته باشند؛
  شناسه آزاد در JSON جایگزین ارتباط معتبر نیست.

## بررسی

۹۱ تست Policy، ۹ آزمون HTTP و ۷ آزمون واقعی PostgreSQL 18 موفق؛ FK مصرف‌شده، قفل نسخه، rollback و Audit بررسی شدند. DB آزمون مستقل بود و حذف شد؛ داده کاربردی حذف نشد. Typecheck و Production Build کل پروژه موفق؛ lint کلی فقط ایراد قبلی تقویم مشترک را دارد.
