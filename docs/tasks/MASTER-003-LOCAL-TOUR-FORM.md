# تکمیل محلی فرم نوع تور — PC-B

وضعیت: آماده Review؛ انتشار با تأیید کاربر در 2026-08-31 روی `codex/pc-b-master-data-travel-form-details`، Stacked روی حذف امن. نسخه کامل روی لوکال فعال می‌شود؛ گزارش زیر نتیجه مرحله پیاده‌سازی مستقل است.

## محدوده

فرم Popup نوع تور شامل کد خودکار فقط‌خواندنی، عنوان فارسی/انگلیسی، دامنه داخلی/خارجی/هر دو، شرح، ترتیب نمایش، وضعیت و اطلاعات فقط‌خواندنی استفاده/آخرین تغییر است. پروفایل همچنان Popup باقی می‌ماند.

ذخیره مشخصات و وضعیت یک درخواست و یک تراکنش با کنترل نسخه و Audit است؛ وضعیت دلخواه بدون مجوز پذیرفته نمی‌شود. کد، زمان و شناسه تغییر‌دهنده توسط کاربر قابل جعل نیستند.

## سازگاری و وابستگی

- Producer/Consumer: Master Data API و Web. `values.status` اختیاری در POST/PATCH نوع تور افزایشی و سازگار با v12 است. کلاینت قدیمی بدون این فیلد همان رفتار قبل را دارد.
- attributes نوع تور شامل `updatedByUserId` از رکورد ذخیره‌شده و `usageCount: null`، `usageStatus: UNAVAILABLE` است؛ تعداد استفاده قابل ثبت دستی نیست.
- API عمومی IAM کاربران، فقط با مجوز خودش، منبع نام نمایشی است. خطای دسترسی/اتصال مانع نمایش نوع تور نمی‌شود؛ شناسه واقعی تغییر‌دهنده به‌عنوان fallback نمایش داده می‌شود.
- هیچ قرارداد واقعی برای شمارش محصولات مصرف‌کننده نوع تور در این checkout وجود ندارد؛ اتصال نهایی نیازمند Handoff مالک محصولات است. `null` با صفر برابر نیست و عدد ماکاپ Seed نمی‌شود.
- Schema، Migration، داده محلی، Customers، IAM، Parent Branch، سرورها و Dependency/Lockfile تغییر نمی‌کنند. تغییرات حذف امن/همکاری/مسیر درختی حفظ می‌شوند. این اصلاح محلی است و Commit/Push نمی‌شود.

## بررسی

- ۵۸ آزمون جدید: ۲۹ آزمون API برای اعتبارسنجی، مجوز وضعیت، یک تراکنش/Audit، کنترل نسخه و metadata؛ ۲۰ آزمون مدل فرم؛ ۵ آزمون قرارداد مجوزدار نام تغییر‌دهنده؛ ۴ آزمون SSR کامپوننت واقعی فرم.
- مجموعه جاری Web: ۲۴۲ تست موفق در ۴۴ فایل. مجموعه جاری API: ۳۸۴ تست موفق و ۱۱ skipped در ۵۵ فایل؛ این اعداد شامل تغییرات هم‌زمان سایر کارها نیز هستند.
- typecheck API/Web و lint فایل‌های متاثر موفق‌اند. `git diff --check` بدون خطای whitespace است.
- کامپایل Production API و Build Production Web/webpack در پوشه موقت، بدون دست‌زدن به خروجی ساخت سرورهای مشترک، موفق‌اند. Build Web شامل مسیرهای اطلاعات پایه است.
- مرورگر آزمایشی فاقد Session بود و به Login هدایت شد؛ آزمون تعاملی احراز‌شده و ذخیره در پایگاه داده محلی در این کار انجام نشده‌اند. سرورها، رمزها و Sessionها تغییر نکردند.
- Schema/Migration تغییر ندارد؛ آزمون‌های اختصاصی دیتابیس نیازمند محیط خودشان skipped مانده‌اند. این گزارش ادعای اجرای آن‌ها را ندارد.
- نمایش تعداد واقعی محصولات هنوز کامل نیست: نبود قرارداد مالک محصولات صریحاً «در انتظار اتصال محصولات» نمایش داده می‌شود، نه صفر یا داده نمونه.
