# MASTER-008 — فیلدهای نوع هواپیما

## نتیجه

- عنوان فارسی نوع هواپیما از فرم ایجاد/ویرایش، فهرست، پنجره پروفایل و ستون‌های خروجی Excel حذف شد.
- سازنده و مدل در Web به یک ورودی و ستون با عنوان «سازنده و مدل» تبدیل شد. مقدار پیشنهادی با جداکننده روشن ثبت می‌شود؛ نمونه: `Airbus / A320-200`.
- نام نمایشی فهرست و پروفایل از عنوان انگلیسی، مقدار ترکیبی سازنده/مدل یا کد رکورد به‌دست می‌آید و دیگر نام فارسی ذخیره‌شده را نمایش نمی‌دهد.
- داده‌های آزمایشی ساده و واقع‌نما با ساختار جدید هماهنگ شدند.

## سازگاری و مالکیت

مدل پایگاه داده فعلی برای سازگاری با Ticket Catalog و مصرف‌کنندگان قبلی همچنان ستون‌های `name`، `manufacturer` و `model` را نگه می‌دارد. سرویس Master Data ورودی جدید `manufacturerModel` را در مرز API اعتبارسنجی و به `manufacturer` و `model` تبدیل می‌کند و `name` داخلی غیرنمایشی را از عنوان انگلیسی یا همان دو مقدار می‌سازد. Payload قدیمی جداگانه نیز همچنان پذیرفته می‌شود.

این واحد کار هیچ Schema، Migration، Seed عملیاتی، Dependency/Lockfile، IAM، قرارداد مرکزی یا دسترسی مستقیم به جدول ماژول دیگر ایجاد نکرده است. PR #232 و PRهای تاریخی Master Data دست‌نخورده باقی مانده‌اند.
