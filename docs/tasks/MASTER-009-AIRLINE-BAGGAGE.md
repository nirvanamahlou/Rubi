# MASTER-009 — انتقال قواعد بار به بخش ایرلاین

## درخواست

قواعد بار دیگر به‌عنوان تب مستقل حمل‌ونقل نمایش داده نشود و مدیریت آن داخل بخش ایرلاین قرار بگیرد.

## پیاده‌سازی

- «قواعد بار» از ناوبری سطح اول حمل‌ونقل حذف شد.
- «ایرلاین‌ها» یک زیرناوبری داخلی با دو نمای «فهرست ایرلاین‌ها» و «قواعد بار» دارد.
- در نمای قواعد بار، عنوان و مالکیت صفحه همچنان «ایرلاین‌ها» باقی می‌ماند و فرم افزودن/ویرایش، فیلترها، KPI، جدول و عملیات قواعد بار در همان بخش اجرا می‌شوند.
- مدل داده فعلی حفظ شد: هر قانون بار رکورد مستقل Master Data و دارای ارتباط واقعی `airlineId` است. داده‌ای در رکورد ایرلاین کپی یا تعبیه نمی‌شود.
- API عمومی، قراردادهای مشترک و مصرف Ticket Catalog تغییر نکردند؛ در نتیجه مصرف‌کنندگان فعلی همان منبع پایدار قواعد بار را ادامه می‌دهند.
