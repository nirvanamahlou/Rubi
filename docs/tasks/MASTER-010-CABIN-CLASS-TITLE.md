# MASTER-010 — عنوان انگلیسی کلاس پروازی

## درخواست و نتیجه

- عنوان فارسی از فرم ایجاد و ویرایش کلاس پروازی حذف شد.
- عنوان انگلیسی اجباری و با علامت فیلد الزامی نمایش داده می‌شود؛ Web و API هر دو ثبت ناقص یا مقدار خالی را رد می‌کنند.
- فهرست، پنجره پروفایل و خروجی Excel دیگر عنوان فارسی یا ستون داخلی `name` را نمایش نمی‌دهند.
- نام نمایشی رکورد از `englishName` و برای رکورد قدیمی فاقد آن، از کد پایدار رکورد به‌دست می‌آید.
- Fixtureهای آزمایشی ساده و واقع‌نما با ورودی English-only هماهنگ شدند.

## سازگاری و مرز داده

مدل فعلی `MasterCabinClass` برای سازگاری دیتابیس، Ticket Catalog و FK قواعد بار همچنان ستون غیرتهی `name` را نگه می‌دارد. سرویس Master Data در ایجاد و در هر ویرایش `englishName`، مقدار داخلی `name` را از همان عنوان انگلیسی همگام می‌کند. بنابراین حذف عنوان فارسی بدون Migration، تغییر Schema، شکستن شناسه رکورد یا کپی داده در مصرف‌کنندگان انجام شده است.

این واحد کار هیچ Migration/Schema، قرارداد عمومی مشترک، Dependency/Lockfile، IAM، داده عملیاتی یا فایل متعلق به PC-A را تغییر نمی‌دهد. شاخه از HEAD آماده بازبینی PR #240 ساخته شده و به‌ترتیب به PRهای #240 و #236 وابسته است. مالک محصول در ادامه، Push و ادغام PR تجمیعی #241 با `develop` را صریحاً مجاز کرد.
