# Nora hybrid provider rollout

PC-C implements the hybrid Agent on top of the OpenAI acceptance candidate. Opt in with `ASSISTANT_MODEL_PROVIDER=hybrid`. A narrow set of simple context-free greetings and authorized contract counts use Groq. Other data Agent requests, follow-ups, report comparisons and questions with a selected record use GPT-4.1. Routing happens once per user turn. The existing deterministic count fast path, guide selector and legacy conversation path retain their behavior.

Supply `OPENAI_API_KEY` privately for single-key use or `OPENAI_KEY_POOL_FILE` with an absolute path to a private version-1 credential file. The pool entries use the same fields as the Groq pool, including stable credential IDs and actual provider organization aliases. Use the same organization alias for credentials with shared billing and quota. An OpenAI rate or credit rejection cools down the whole configured organization before a different eligible billing group is considered. A revoked key is disabled independently. Auth, project access, provider terms and spending limits still apply. A second key in an exhausted organization does not grant additional capacity.

Release prerequisites: green CI on the review head and integrated source, a fresh restricted project credential, an approved OpenAI egress route from the candidate runtime, and a successful synthetic model call through that route. Verify legitimate routes for both providers before activation, preserve the peer containers and settings, and retain the prior Nora container for rollback under the existing release lock. Finish by checking authenticated real-account answers from both model routes without recording business values in Git.

PC-C verification: mocked routing and organization-aware quota failover pass along with the existing service regression suite. The production Nora container and Germany tunnel are healthy. Its existing proxy does not establish an HTTP connection to the OpenAI API. Production activation and real-account browser checks are pending a working approved route and production credentials.
