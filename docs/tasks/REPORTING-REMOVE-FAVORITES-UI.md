# REPORTING-REMOVE-FAVORITES-UI

## هدف

ساده‌سازی تجربه کاتالوگ و «گزارش‌های من» با حذف Favorite دیداری که در نسخه فعلی
ارزش عملیاتی مستقل و پایداری قابل اتکایی برای کاربر نداشت.

## تغییرات

- آیکن ستاره و اکشن افزودن/حذف Favorite از تمام کارت‌های کاتالوگ حذف شد.
- نوار دوگزینه‌ای «همه گزارش‌های من / محبوب‌ها» حذف شد و فهرست گزارش‌های من
  مستقیماً نمایش داده می‌شود.
- ذخیره گزارش همچنان از API موجود انجام می‌شود، اما گزارش تازه با مقدار
  `isFavorite=false` ثبت می‌شود.

## مرزها

هیچ API، قرارداد، Schema/Migration، Seed/Data، Permission، Dependency یا Lockfile
تغییر نکرد. سازگاری مسیرهای قدیمی Favorite در لایه Navigation دست‌نخورده باقی ماند
تا لینک قدیمی موجب خطا نشود، اما دیگر ورودی دیداری برای آن وجود ندارد.
