# آخرین نسخه ذخیره‌شده در PDF رزرواسیون

مالک اجرا: PC-A؛ شاخه `codex/pc-a-reservation-latest-pdf-1109`.

طبق درخواست مالک محصول، دانلود معمولی PDF فرم رزرواسیون باید آخرین تنظیمات
ذخیره‌شده، از جمله NOTICE، تاریخ و مبلغ را نشان دهد؛ ارسال ایمیل شرط دانلود نیست.
قبلاً مسیر GET تنظیمات جاری را با آخرین snapshot ارسالی جایگزین می‌کرد.
این جایگزینی حذف شد. لینک QR همان خروجی نیز از آخرین نسخه ذخیره‌شده ساخته می‌شود؛
محتوای لینک‌های عمومی قبلی بازنویسی نمی‌شود.

در حالت انتخاب هتل، ابتدا محدوده همان هتل انتخاب می‌شود و سپس تنظیمات جاری همان
فرم چاپ می‌شوند. تغییرات ذخیره‌نشده مرورگر وارد PDF نمی‌شوند. نسخه‌های ارسالی
قبلی، شماره نسخه و revisionهای سابقه حذف یا بازنویسی نمی‌شوند و نمایش سابقه همان
snapshotهای قبلی را نگه می‌دارد. دانلود تغییری در وضعیت ارسال ایجاد نمی‌کند.

قالب PDF، CSS و ظاهر فرم تغییر نکرده‌اند. مسیر واچر، گیت تحویل مالی قرارداد و
مجوزهای دسترسی حفظ شده‌اند. مسیر ایمیل تغییری ندارد و ارسال واقعی تا تحویل IT
غیرفعال می‌ماند؛ هیچ تنظیم، داده عملیاتی یا migration اجرا نشده است.

اعتبارسنجی:۷۹ تست Web مربوط به مسیر PDF، حفظ قیمت ارسالی، NOTICE جاری، فرم هتل،
محتوای QR، کنترل واچر، دانلود و ذخیره بدون ایمیل موفق‌اند.۳۰ تست API مربوط به
snapshot مستقل فرم‌های هتل، ایمیل و حالت خاموش موفق‌اند. بررسی نهایی lint،
typecheck، build و تمام گیت‌های CI روی آخرین commit پیش از merge الزامی است.

این تغییر استقرار عملیاتی انجام نمی‌دهد. شواهد نهایی CI و merge در PR ثبت می‌شوند.
