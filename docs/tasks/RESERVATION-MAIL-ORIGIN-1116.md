# رفع رد مبدأ ارسال PDF رزرواسیون پشت پراکسی

مالک اجرا: PC-A؛ شاخه `codex/pc-a-reservation-mail-origin-1116`.

خطای گزارش‌شده پیش از مجوزهای API رخ می‌داد: مبدأ مرورگر HTTPS بود ولی مسیر POST
آن را با مبدأ داخلی HTTP کانتینر مقایسه می‌کرد. روی handler واقعی Web، درخواست
ساختگی با نسخه نامعتبر و بدون نشست، برای مبدأ داخلی۴۰۰ و برای مبدأ عمومی۴۰۳
برگرداند. این آزمون هیچ PDF، صف یا ایمیلی ایجاد نکرد.

تنظیم خصوصی Web با نام `RESERVATION_MAIL_WEB_ORIGIN` مبدأ مجاز را صریح تعیین
می‌کند. مقدار عملیاتی `https://avinaofficial.ir` است. مسیر POST فقط Origin دقیق
مرورگر را با همین مقدار مقایسه می‌کند؛ X-Forwarded-Host و X-Forwarded-Proto ورودی
برای اعطای دسترسی قابل اعتماد نیستند. مقدار نامعتبر، مسیر، query، اطلاعات ورود،
مبدأ خارجی، مبدأ خالی و HTTP عمومی رد می‌شوند. در محیط مستقیم بدون تنظیم، مقایسه
هم‌مبدأ قبلی حفظ می‌شود؛ HTTP فقط برای loopback در تنظیم صریح مجاز است.

احراز هویت، شعبه، مجوز مدارک، نسخه ذخیره‌شده، HMAC، محدودیت اندازه PDF و گیرنده
همگی بدون تغییر باقی می‌مانند. ظاهر فرم و قالب PDF تغییری ندارند. ارسال برای
آزمون دستی مالک فعال می‌ماند؛ Agent برای پذیرش این اصلاح ایمیل ارسال نمی‌کند.

۶۵ تست Web مربوط به مسیر ایمیل، PDF و ذخیره قیمت موفق‌اند. برنامه انتشار محدود
Web باید روی image واقعی همان لحظه ساخته شود، همه overlayهای همکاران، staticهای
قدیمی، تنظیمات و کلیدهای فعلی را حفظ کند. فایل route واقعی با مبنای شاخه از نظر
متن یکسان تأیید شد. قبل از انتشار، گیت‌های نهایی، قفل استقرار، پشتیبان رمزگذاری‌شده
و rollback لازم‌اند. صحت مبدأ عمومی و رد مبدأ خارجی با فرمان ساختگی نامعتبر و
بدون نشست آزمایش می‌شود؛ نه با ارسال قرارداد واقعی.

## ترمیم یکپارچه‌سازی CI

مبنای ادغام‌شده PR1745 سه ارجاع ناقص در سرویس/کلاینت درخواست‌ها داشت. فیلد
تأیید استثنای HR از پاسخ جانشین و audit ارجاع نامرتبط حذف شد؛ در مسیر صحیح HR
حفظ می‌شود. سرویس عمومی IAM موجود به‌صورت اختیاری تزریق شد و نبود آن همچنان
تأیید بدون رضایت جانشین را رد می‌کند. تست‌های هویت، تأیید صریح، audit و جدایی
payload پاسخ جانشین اضافه شدند:۳۴ تست API و۲۹ تست Web موفق‌اند. این ترمیم صرفاً
برای کامل‌شدن گیت‌های سورس است و در overlay عملیاتی اصلاح ایمیل قرار نمی‌گیرد.
