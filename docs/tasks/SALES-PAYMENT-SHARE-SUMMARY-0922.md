# SALES-PAYMENT-SHARE-SUMMARY-0922

## درخواست

کاربر در پنجره «افزودن پرداخت» باید مبلغ کل قرارداد را ببیند و هنگام ورود مبلغ بداند این پرداخت چه سهمی از کل و چه مانده‌ای پس از تأیید ایجاد می‌کند.

## پیاده‌سازی

- خلاصه برای ارز انتخاب‌شده و مستقل از سایر ارزهای قرارداد نمایش داده می‌شود.
- مبلغ کل، پرداخت تأییدشده، مبلغ در انتظار مالی، مبلغ جاری، درصد مبلغ جاری از کل و مانده پس از تأیید همین پرداخت نمایش دارند.
- مبلغ بیشتر از مانده با مقدار مازاد مشخص می‌شود.
- ورودی مبلغ از کنترل استاندارد MoneyInput با جداکننده هزارگان استفاده می‌کند.
- محاسبات بر پایه Decimal چهاررقم اعشار و BigInt هستند و به Number تبدیل نمی‌شوند.

## محدوده و بررسی

- API، Finance، قرارداد مشترک، Schema/Migration، Permission، Dependency/Lockfile و داده عملیاتی تغییر نکردند.
- ۹ تست هدفمند مدل و UI موفق.
- lint فایل‌های متاثر، typecheck کامل Web و build تولیدی Web با ۵۰ route موفق.
