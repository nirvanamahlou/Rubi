# تعریف تور در گروه فروش — PC-A — 2026-09-29

درخواست مالک: بخش تعریف تور از صفحهٔ مدیریت بلیت جدا شود و به‌عنوان آخرین گزینهٔ گروه «فروش و ارتباط با مشتری» نمایش داده شود؛ فروش بتواند تعریف تور را بسازد، ویرایش کند و حذف کند.

## نتیجه

- مسیر مستقل `/sales/tours` همان رابط Ticket Catalog را برای تعریف تور و خدمات به‌کار می‌برد. زبانهٔ تور از صفحهٔ مدیریت بلیت برداشته شد؛ لینک تعریف تور آخرین گزینهٔ گروه فروش است.
- مالکیت مدل، سرویس و دادهٔ تور همچنان Ticket Catalog است. Sales از همان API عمومی تور استفاده می‌کند و به جدول ماژول دیگری دسترسی مستقیم ندارد.
- مجوز محدود `ticket_catalog.tours.manage` برای ساخت/ویرایش/حذف تعریف و ثبت نوبت اضافه شد. مجوز کلی `ticket_catalog.manage` همچنان کار می‌کند. پیش‌فرض پیشنهادی نقش فروش این مجوز و صفحهٔ تور را شامل می‌شود؛ هیچ پروفایل حساب واقعی خودکار تغییر نکرد.
- حذف با شعبه و نسخهٔ مورد انتظار انجام می‌شود، به ایجاد نوبت قفل سازگار دارد و فقط برای توری مجاز است که هیچ نوبت ثبت‌شده‌ای ندارد. تور دارای نوبت با تعارض واضح رد می‌شود تا سوابق سفر حفظ شوند. Migration ندارد.

- ۳۰ تست هدفمند API و ۵۲ تست هدفمند Web موفق‌اند؛ تست‌ها شامل مجوز محدود فروش، ساخت و ویرایش، DELETE نسخه‌دار، رد نسخهٔ قدیمی، جلوگیری از حذف تور دارای نوبت، مسیر/ترتیب منو و نمایش کنترل حذف‌اند.
- lint کامل API و lint فایل‌های متاثر Web، typecheck کامل API و Web، build API و build تولیدی Web موفق‌اند؛ `/sales/tours` در خروجی ۵۵ route ساخته شد.
