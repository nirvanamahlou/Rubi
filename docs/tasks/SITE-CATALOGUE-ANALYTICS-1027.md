# قرارداد کاتالوگ و گزارش نیایش — PC-D — 2026-10-27

Producer: Niyayesh `erp_panel`. Consumer: Nora Integrations, task branch `codex/pc-d-site-catalogue-analytics-1027`. مقصد یکپارچه‌سازی Nora همان PC-D-Integration است. هیچ تغییر main/develop یا Migration/Dependency در این واحد وجود ندارد.

## قرارداد و مالکیت

- `GET /api/v1/integration/catalogue/{resource}/schema`: JSON Schema نسخه ۱ مستقیماً از DTOهای native؛ حق ایجاد، ویرایش و انتشار جداگانه. منابع: تور، هتل، بلیت/خدمات، ویزا، مقصد، کشور، شرکت هواپیمایی، دسته‌بندی و محتوا. دسته‌بندی فقط ایجاد دارد چون سایت PATCH ندارد.
- `GET .../catalogue/{resource}/value/{id}`: ورودی‌های قابل ویرایش همراه نسخه journal و شناسه خارجی؛ حذف فیلدهای output-only، حفظ تمام داده‌های تو در تو و Decimal.
- ثبت از همان POST/PATCHهای native سایت انجام می‌شود؛ فرم عمومی، قواعد کسب‌وکار موازی ایجاد نمی‌کند. PATCH فقط فیلدهای تغییرکرده را ارسال می‌کند. X-ERP-Version، امضای actor/scope، nonce و receipt اتمیک قبلی پابرجا هستند.
- چک‌باکس‌های مدیریت هر منبع، گزارش و انتشار در فهرست موجود IAM اضافه شده‌اند. مجوز نورا، allowlist سمت سرور و مجوز حساب شخصی سایت باید همگی اجازه دهند. مالک سایت یا نقش owner به کاربران نورا داده نمی‌شود.
- فرم از تمام فیلدهای DTO پشتیبانی می‌کند؛ تصاویر فعلاً با نشانی موجود سایت وارد می‌شوند. آپلود فایل تصویر از داخل نورا در این برش اضافه نشده است؛ ورود Excel قبلی حفظ می‌شود.

## گزارش نسخه ۱

- `GET /api/v1/integration/report?from=YYYY-MM-DD&to=YYYY-MM-DD`: حداکثر ۳۶۶ روز، روزهای تقویمی تهران و ذخیره/مقایسه UTC؛ انتهای بازه exclusive است.
- کاربران جدید: حساب مشتری حذف‌نشده ایجادشده در بازه؛ شمارش کل کاربران/تور/هتل جداگانه و بدون فیلتر زمان ایجاد.
- سفارش: ایجادشده در بازه. فروش: paid و غیرcancelled بر اساس payment_confirmed_at (داده قدیمی فاقد آن با updated_at). مبلغ جمع unit_price × quantity اقلام سفارش به تفکیک ارز اصلی است؛ رسید دریافت وجه یا تأیید Finance نورا نیست. مبلغ نامعلوم/فقدان اقلام با مبلغ کامل برابر نیست.
- منتظر: وضعیت فعلی پرداخت‌نشده، لغونشده، منقضی‌نشده از میان سفارش‌های ایجادشده در بازه؛ تاریخچه وضعیت گذشته نیست.
- drilldown از همان predicate گزارش با `report_metric`, `from`, `to` استفاده می‌کند؛ بدون دریافت مستقیم جدول سایت توسط نورا.
- بازدید: PageView موجود سایت، تعداد page views و distinct session_key کل بازه و روزانه. شناسه در localStorage مرورگر عمومی سایت است؛ معادل انسان یکتا یا کاربر ثبت‌نام‌شده نیست. جمع یکتاهای روزانه برای کل بازه استفاده نمی‌شود؛ سابقه قبل از راه‌اندازی tracker قابل بازیابی نیست.
- اتصال dashboard فقط با registrySystemId صریح است؛ نام/دامنه برای حدس زدن اتصال استفاده نمی‌شود. آمار یک سایت به مجموع چهار سایت تعمیم داده نمی‌شود. آکادمی فروش مستقیم سفر محسوب نمی‌شود. ارزها تبدیل یا با هم جمع نمی‌شوند.
- activity فقط شناسه خارجی، نوع تغییر، منبع و زمان؛ محتوای حساس credential یا staff report منتقل نمی‌شود.

## سازگاری و پذیرش

قراردادها افزایشی‌اند؛ دریافت منابع، OIDC شخصی، workflowهای Excel و ثبت امن قبلی حفظ می‌شوند. هیچ تغییری به Finance/Reservations یا تأیید تجاری آنها اعمال نمی‌شود. اتصال در این تحویل فقط به نسخه محلی نیایش است؛ سه سایت دیگر آماده اتصال می‌مانند.

مقادیر فرم از allowlist فیلدهای Input روی آبجکت native بارگذاری‌شده تولید می‌شوند؛ DTO نمایشی عمومی ممکن است قیمت‌های قدیمی را فیلتر کند و برای فرم ویرایش استفاده نمی‌شود. FK مقصد و دسته‌بندی و مجموعه‌قیمت‌های قدیمی در فرم حفظ می‌شوند. بازخوانی نهایی HTTP فرم‌های رکوردهای موجود در تمام منابع دارای داده و ۳۶ فیلد تور را تأیید کرد.
