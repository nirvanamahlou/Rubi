PC-B؛ شاخه codex/pc-b-workbench-interactions؛ مرجع تصاویر544تا551. تغییر B2B9b1c33c حفظ شد.

## اجراشده

- حذف متن راهنمای تم از تنظیمات و حذف فقط دکمه «اسناد و فایل‌ها» داخل فایل‌های میزکار؛ آرشیو و منوی اصلی حفظ شدند.
- تنظیمات در دو بخش اطلاعات حساب/امنیت؛ تب‌های بزرگ‌تر و وسط‌چین؛ چهار KPI با رنگ‌های مستقل سازگار با dark mode.
- پیام‌رسان دو ستونی، جست‌وجوی واحدهای مالی/فروش/رزرواسیون/AI، قالب‌ها و ایموجی؛ پنجره پیام جدید برای انتخاب واحد.
- دکمه‌های درخواست، پیام و یادداشت جدید؛ فرم اولیه درخواست با عنوان/شرح/واحد/اولویت/مرجع پرونده.
- سه قالب یادداشت و چک‌لیست قابل افزودن/حذف/تیک‌زدن و خط‌خوردن در پیش‌نویس. نمونه‌ها به‌عنوان یادداشت ذخیره‌شده معرفی نمی‌شوند.

## بخش تکمیل‌نشده و دلیل

ارسال پیام، پاسخ AI، ایجاد درخواست/ارجاع، ذخیره خصوصی یادداشت و ایجاد چند یادداشت در حساب واقعی انجام نشده است. هیچ سرویس عمومی پایدار موجود در runtime برای آن‌ها نیست؛ جداول مستقل همراه با permission/branch/member isolation، API، audit و migration لازم‌اند. فرم‌ها صریحاً ثبت را غیرفعال نشان می‌دهند؛ هیچ موفقیت، تاریخچه یا مخاطب واقعی ساختگی ایجاد نشد.

هماهنگ‌کننده در همین اجرا جدیدترین unified4acdcb6 را بررسی و تأیید کرد که Migration/Central Docs و IAM/Sales/Travel نزد مالک Reservations PC-A باقی است و اختیار handoff ندارد. این تجمیع قفل‌ها را آزاد نمی‌کند. اشاره قدیمی گزارش011 به PR153 به‌عنوان Reservations نادرست است: PR153 مربوط به Finance است. ملاک قفل آخرین WORK_ASSIGNMENTS است، نه آن شماره PR.

برای تکمیل: انتقال صریح محدوده Migration لازم برای Workbench، قرارداد public IAM برای مخاطبان مجاز/واحدها و اجرای سرویس جدید. تغییر Backend و migration پیش از انتقال آغاز نشد؛ API cutover قبلاً ردشده تکرار یا دور زده نشد. درخواست عمومی رابط فعلی همه فیلدهای PRD یا عملیات مالی/صدور را پیاده نمی‌کند.
